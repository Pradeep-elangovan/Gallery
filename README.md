# Pin Gallery

A gallery app where you can **pin** photos and videos so they appear at the top of the grid (they scroll away with everything else — nothing is sticky).

Features: pinned-first grid (main grid and per album), albums, favorites, search, sort, photo/video filter, pinch-zoom viewer, video player, share, delete via a 30-day recycle bin, details/EXIF, slideshow, duplicate finder, map of geotagged photos, set-as / edit-with.

## Get the APK
Push to `main` (or run the **Build APK** workflow manually) and download `PinGallery-debug-apk` from the run's Artifacts.
